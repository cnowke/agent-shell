* Replay docstring fix

This is an Agent Shell bug, not a Shell Maker quoting bug.
=tests/agent-shell-fakes.el= has unescaped quotes in the docstring of
=agent-shell-fakes--synth-exchange=. They terminate the docstring early,
so calling the helper evaluates =session/new= as a variable and raises
=(void-variable session/new)=. Partial captures that need a synthetic
initialization handshake therefore cannot be replayed reliably.

The fix escapes the examples' quotes and clarifies the PARAMS sentence.
Two regression tests in =tests/agent-shell-fakes-tests.el= cover synthetic
request resolution and handshake generation for a partial capture.
Both tests were verified to fail before the fix and pass afterward.

The clean contribution branch is =fix/replay-docstring-pr=. Its diff
against the last fetched upstream main contains exactly:

- =tests/agent-shell-fakes.el=
- =tests/agent-shell-fakes-tests.el=

The personal =fix/replay-docstring= branch contains the fix plus notes.
See [[file:replay-docstring-pr-notes.org][replay-docstring-pr-notes.org]] for the upstream reproduction and expected
failure. From the fixed checkout, with the ACP package installed:

* Buffer renames and steering

The coordinated rename branches are required in both repositories.
Agent Shell associates its shell and viewport through buffer objects;
Shell Maker synchronizes internal naming after raw buffer renames.
The changes address stale lookups, old-name reuse, drafts, cleanup,
restart/reload, and the user's C-Enter steering regression.

=agent-shell-rename-buffer= works from the shell or viewport and remaps
the normal rename command. The user's C-Enter binding invokes
=ins/agent-shell-submit-steering=; its local configuration is not committed
to these repositories.

From the Agent Shell rename checkout, with the Shell Maker rename
checkout at =../shell-maker=:

#+begin_src sh

The gate passed 41 tests with zero skips. It exercises fake ACP request
handling, steering around acknowledgements, streaming, viewport drafts
and queues, interrupt, restart/reload, and old-name reuse. It checks loaded
source revisions and requires the essential tests. Use =--shell-maker PATH=
or =--acp PATH= when dependencies are elsewhere.
